# SheetForge

Batch export for Revit 2021-2027 (VX Studio, by Hakim).

**Install:** open the latest release, download `SheetForge-Setup-<version>.zip`, unzip it and double-click **Install SheetForge**. The first time you click Batch Export, sign in with your Microsoft account; the admin approves new accounts.

This repository holds compiled release files only.
